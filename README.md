# US Violent Crime Statistical Analysis

An exploratory data analysis (EDA) project evaluating murder rates across 50 US states using the `USArrests` dataset. Developed as a collaborative academic project.

## Overview
This repository contains a statistical comparison of crime distributions between high and low urbanization cohorts. The project evaluates central tendency, dispersion (IQR, standard deviation), and distribution shape metrics (skewness, kurtosis).

## My Responsibilities
* **Data Processing:** Segmented the dataset based on urbanization thresholds and computed core statistical metrics using **Pandas** and **NumPy**.
* **Data Visualization:** Designed and generated comparative grouped histograms and boxplots using **Matplotlib**, focusing on custom aesthetic formatting to clearly highlight data skewness and outlier behavior.
* **Technical Reporting:** Structured the final analytical report and formatted statistical tables using **LaTeX**.
* **Workflow Optimization:** Leveraged **AI Agents** to debug Python scripts and refine the visual aesthetics of the generated plots.

## Tech Stack
* **Python** (Pandas, NumPy, Matplotlib)
* **LaTeX**
